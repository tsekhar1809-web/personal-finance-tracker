Play ground having two options to select the commands 

1. cy.get() //to locate the elements with the help of supplied CSS selectors 
a. classname  = .classname
b. ID = #id
c. tag name = tagname 
d. attributename="value" = [attribute="value"]

cy.get('selector of UI component').actions or assertions on yielded subject. 
should


2. cy.contains() // also used to detect or identify the element on webpage  but it will search through text you supplied. 

cy.contains('Hello') // where ever we do have Hello text your cypress will go there and try to perform actions and assertions on that UI component.
