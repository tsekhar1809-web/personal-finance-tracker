Today we are setting up the cypress in local computer through npm install
===================================================================
Pre requisites :  

1. nodeJS => download and install nodejs as part of your cypress installation 

why do we need to install nodejs =>cypress developed in java script hence to run java script application nodejs is required to run those application.
a. downloaded nodejs  
b. installed into the computer 
c. set the path in environmental variables.

2. Check the node version installed in your computer is compatible with the cypress supported version number. 

node -v

reference URL :https://docs.cypress.io/guides/getting-started/installing-cypress

3. Setup the IDE VSCode ( visual studio Code) , free to use. 

a. download the VScode https://code.visualstudio.com/Download
b. install the VScode 
c. Go through the intro videos to make your self comfortable with VSCODE IDE
https://code.visualstudio.com/docs/getstarted/userinterface

Open IDE 

================================================================
Setup cypress in your local computer
Create a Project folder => 

1.Open VSCODE IDE 
2. Supply newly created folder to VSCODE through open Folder option 
3. Open the terminal => command prompt with in the IDE
4. Run the installation command n the terminal 
"npm install cypress --save-dev"
this step will take couple of min based on your internet speed.

Reference Terminal content:
