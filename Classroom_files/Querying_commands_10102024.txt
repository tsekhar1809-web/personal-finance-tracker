cy.get('selector') // to locate the element by using the selector 
cy.contains('text') //to locate the element by using the text supplied
cy.get('selector').within(function(){
//only with in the provided selector we can operate these steps 
cy.root() //it will not go to global root => HTML // it points to the root of the provided selector 

})


Note: 
cy.root() yields the root DOM element.//html

The root element yielded is <html> by default. However, when calling .root() from a .within() command, the root element will point to the element you are "within".

cy.root() is a query, and it is safe to chain further commands.
