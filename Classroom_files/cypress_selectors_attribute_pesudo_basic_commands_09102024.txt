What are Pseudo-Elements?
===============================
A CSS pseudo-element is used to style specified parts of an element.

For example, it can be used to:

select the first letter, or line, of an element


select specified child element whenever more children are available 


The syntax of pseudo-elements:
==========================
selector::pseudo-class/element
==========================

:first-child	
p:first-child	Selects every <p> elements that is the first child of its parent

:last-child
p:last-child	Selects every <p> elements that is the last child of its parent

:link	
a:link	Selects all unvisited links

============================================================
CSS [attribute="value"] Selector
============================================================
1. attribute="value"
[attribute]

The [attribute="value"] selector is used to select elements with a specified attribute and value.

2. The [attribute~="value"] selector is used to select elements with an attribute value containing a specified word.


The example [title~="flower"] =>
 will match elements with title="flower", title="summer flower", and title="flower new", but not title="my-flower" or title="flowers".

3. The [attribute|="value"] selector is used to select elements with the specified attribute, whose value can be exactly the specified value, or the specified value followed by a hyphen (-).

Note: The value has to be a whole word, either alone, like class="top", or followed by a hyphen( - ), like class="top-text".

4. The [attribute^="value"] selector is used to select elements with the specified attribute, whose value starts with the specified value.

5. The [attribute$="value"] selector is used to select elements whose attribute value ends with a specified value.

The following [class$="test"] selects all elements with a class attribute value that ends with "test":

Note: The value does not have to be a whole word!  

6. The [attribute*="value"] selector is used to select elements whose attribute value contains a specified value.

The following [class*="te"] => selects all elements with a class attribute value that contains "te":

Note: The value does not have to be a whole word!
